# 交互原型 v0.1

入口：`prototype/index.html`，直接用现代浏览器打开，无需安装依赖或启动服务器。暂定产品名“译界”，可在确认时更换。

## 设计

- 面向开发工具日常使用的低干扰工作台，左侧任务导航，右侧应用列表与方案详情。
- 颜色：背景 #F5F7F6、正文 #202928、辅助 #606B68、强调 #136B58、边框 #DCE3DF、警示 #845B18。
- 字体：Segoe UI / 微软雅黑；数据和路径 Consolas；应用字母标识采用 Georgia。不依赖远程字体、图片或脚本。
- 控件6px圆角，分割线与状态标签区分信息；焦点轮廓明确，适配窄屏导航，尊重减少动画设置。
- 关键视觉对象是原型内的设置画面与对应中文，不使用营销首屏。

## 边界

这是交互原型，不是可安装的汉化程序。扫描、版本、应用、配对码、汉化与恢复记录均为演示。所有状态仅保留当前页面内存，刷新重置；导出由用户主动触发，生成标记为demo的JSON。

不获取本机屏幕、不扫描安装应用、不执行OCR、不修改文件、不调用翻译API、不收集密钥。云端表单仅验证输入格式，不提供真实连通性测试。

## 操作

1. 应用汉化：选择Cursor/Claude → 预览并启用中文 → 勾选演示确认 → 模拟备份并启用 → 恢复与诊断查看记录 → 模拟恢复。
2. 屏幕翻译：选择演示范围 → 开始演示翻译 → 切换原位覆盖/双语/侧栏 → 查看原文 → 暂停。
3. 浏览器：模拟配对Edge/Chrome → 确认 → 断开；网页双语预览独立弹窗。
4. 术语：新增、编辑、搜索、删除确认和JSON导出；重复原文在同范围内拒绝保存，空格内容拒绝保存。
5. 引擎：本地/云端切换；云端地址要求HTTPS且不能内嵌凭据；没有API密钥输入框。

正式开发仍需原型确认、依赖授权检查、真实应用适配与原生模块测试。
