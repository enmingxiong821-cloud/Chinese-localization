Claude Desktop 中文版 —— 使用说明
==================================================

一、怎么用
  双击桌面的「Claude 中文版」图标即可启动。

  它是官方 Claude Desktop 的一份独立副本，装在这里：
      {{安装目录}}

  副本使用自己独立的数据目录，所以：
    - 可以和官方版同时打开，互不干扰；
    - 官方版的登录状态、聊天记录、设置完全不受影响；
    - 副本里是全新环境，第一次启动需要登录一次，之后就一直记得。

  官方版升级后，重新运行一次安装程序即可把中文带到新版本。重复运行是安全的，
  不会重复修改同一个文件。

二、怎么还原
  方法一（最彻底）：直接删除整个目录，中文版就彻底消失，官方版不受任何影响。
      {{安装目录}}

  方法二：运行还原命令，把补丁文件逐字节写回副本、删掉中文语言包、删除快捷方式。
      node "{{安装器目录}}\install-cli.mjs" restore

  还原前请先关闭中文版窗口，否则运行中的副本会把设置重新写回去。

  官方 Claude Desktop 的安装目录和它的数据目录自始至终没有被修改过。

三、安装程序做了什么
  1. 把官方程序文件复制到本地目录（约 700 MB）。
  2. 在副本里加入中文语言包（{{译文条数}} 条，覆盖 {{覆盖率}}），并让界面默认使用中文。
  3. 在副本自己的配置里把语言设为中文，语言设置只写在副本内部。
  4. 在桌面和开始菜单创建快捷方式。

  没有做的事：
    - 没有修改官方程序目录里的任何文件；
    - 没有修改官方版的数据或配置；
    - 没有修改程序本身，没有破坏数字签名；
    - 没有关闭自动更新；
    - 没有复制、导出或上传你的登录凭据；
    - 没有代理或改写网络流量。

四、已知情况
  - 极少数提示仍会显示英文：它们来自程序主体，不在语言包范围内。
  - 副本有自己的登录状态，与官方版分开：在副本里登录一次即可，不会串用官方版的凭据。
  - 本副本基于官方 {{官方版本}} 制作。官方大版本更新后，建议重新运行安装程序
    （安装程序会自动识别版本变化并刷新副本，副本内的聊天记录不受影响）。

五、出问题时
  - 提示找不到官方 Claude：请先安装官方 Claude Desktop，再重新运行安装程序。
  - 提示缺少 Node.js：请安装 Node.js LTS（https://nodejs.org/）后重新运行安装程序。
  - 想确认安装是否完好：运行
        node "{{安装器目录}}\install-cli.mjs" verify
