# 混合架构与首版范围

状态：用户已选择两种技术路线有机结合；以下为融合方案，尚未实现或进行性能验证。交互原型确认后进入正式开发。

## 1. 分工

| 模块 | 技术方向 | 责任 |
| --- | --- | --- |
| 桌面主界面 | Electron + React + TypeScript | 应用列表、改动预览、屏幕翻译控制、词典、引擎设置、恢复中心 |
| 共享核心 | TypeScript | 术语、占位符校验、任务取消、缓存、翻译服务适配、覆盖率报告 |
| 应用汉化驱动 | Node.js / TypeScript | 只读扫描、版本指纹、语言包生成、受控资源修改、备份恢复 |
| Windows 辅助进程 | C# / .NET | UI Automation 取词、窗口捕获、坐标转换、快捷键与原生覆盖窗口 |
| 浏览器插件 | TypeScript，构建工具待依赖核验 | Chrome / Edge 网页取词、双语渲染、共享术语；禁止直接访问应用修改能力 |
| OCR 工作进程 | 成熟 OCR 组件，具体实现待评估 | 图像转文本和位置；候选 RapidOCR / ONNX Runtime，不预设必须安装 Python |

不额外开发完整 WPF 管理界面；Windows 覆盖层的具体绘制方式通过小范围验证后选定。C# 模块不重复维护翻译服务、词典及应用汉化业务。

## 2. 通信与权限

- 渲染界面通过受限 preload API 调用主进程；关闭渲染层 Node 集成，按功能校验参数与来源。
- 主进程与 Windows 辅助进程优先采用受当前用户访问控制的命名管道；消息携带协议版本、请求标识、超时和取消标识，限制消息体积。
- 辅助进程默认普通用户权限。需要提升权限的资源修改应作为独立、短生命周期操作，展示具体文件及计划后执行。
- 浏览器与桌面优先评估 Native Messaging，需用户安装并注册主机；不默认开放任意本地 HTTP 控制端口。
- 页面内容、OCR 文本、翻译结果均视为数据，不执行其中的命令，不允许其决定文件路径或注入脚本。
- 第三方适配代码与词典分开管理；适配器不可仅因下载成功就自动执行，词典不得夹带可执行代码。

## 3. 应用直接汉化

Cursor 优先验证语言包与 NLS 资源路线；Claude 优先验证外部语言资源路线。报告中的覆盖率及版本观察不外推到其他版本。

处理顺序：扫描 → 生成修改计划 → 校验适配版本 → 备份 → 临时副本生成 → 校验 → 用户确认具体改动 → 应用 → 检查 → 保留恢复记录。

运行时注入仅作为经过验证的适配能力，不承诺任意 Electron 支持；调试连接只允许本地使用，操作结束后释放。修改 asar 或签名不属于首版默认路线。

不改写代码、路径、模型标识、终端命令或用户输入；可见文本也需明确语境与适配规则。原版备份不得覆盖升级后的不同版本。

## 4. 屏幕与网页翻译

首版覆盖按需整屏、指定窗口、指定区域；区域持续翻译先在技术验证中检查。UIA 可用时优先取词，否则使用捕获与 OCR。

显示支持原位覆盖、双语侧栏和浮窗；只有仍对应当前画面的结果可以显示。检查移动、遮挡、最小化、多屏 DPI、译文溢出以及覆盖层重复识别。

浏览器先面向 Chrome / Edge；网页翻译与桌面界面复用核心协议和术语格式，不共享 DOM 操作代码。页面权限按需授予，浏览器特权页等不可操作场景明确提示。

本地与云端翻译均纳入接口设计；本地 OCR 不表示全链路离线。未经选择不自动向另一服务发送内容。截图默认不落盘，密钥不保存在普通词典、同步包或日志中。

## 5. 原型范围

采用可直接打开的 HTML / CSS / JavaScript 原型，演示数据明确标注，不模拟为真实扫描或真实汉化成功。

页面：应用中心、应用详情与汉化预览、屏幕翻译、浏览器连接、术语库、翻译引擎、恢复与诊断。

交互闭环：选择演示应用 → 查看覆盖范围与计划 → 模拟备份和汉化 → 查看记录 → 模拟恢复；选择演示画面 → 切换译文模式 → 暂停与查看原文；编辑术语 → 搜索验证 → 导出；引擎配置仅演示校验，不请求真实服务。

原型不得读取真实应用内容、修改安装目录或调用收费服务。正式功能使用不同状态与真实结果，不能复用模拟成功分支。

## 6. 验证与下一阶段

1. 原型：按钮、表单、弹窗、键盘操作、窄屏与宽屏布局验证，用户确认后再正式实现。
2. 汉化驱动：在合成 fixture 上验证未知版本拒绝写入、占位符保护、幂等、失败恢复及跨版本恢复拒绝。
3. 原生模块：真实窗口小范围验证 UIA、捕获、覆盖和取消；测量后决定具体组件，不先承诺延迟或资源占用。
4. 集成：验证通信参数、消息大小、进程退出、取消与超时；检查插件不能调用应用改包接口。
5. 依赖复用：引入前读取源码与许可证，记录版本、来源、修改和分发义务；不直接整体搬入未审计的汉化脚本。

当前无需常驻 Web 后端，不提前分配占用服务端口；正式开发服务器需要端口时再检查冲突并记录。无数据库服务账号需求，不在文档存储真实凭据。
