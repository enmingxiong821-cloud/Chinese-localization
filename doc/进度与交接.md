## 已定决策（不要再问）

1. **只做 Claude Desktop。** Cursor、实时翻译、OCR、浏览器插件均为范围外。
2. **交付形态**：双击 `installer/安装.cmd` 调 Node；`install` / `verify` / `restore` 三个动词；
   幂等可重复运行；桌面与开始菜单各一个快捷方式；说明只放一个 `说明.txt`。
3. **落地路径是可写副本**，不给官方安装原地打补丁。副本用独立 userData（启动器带
   `--user-data-dir`），与官方版可同时运行、互不抢单实例锁。
4. **译文表只存 `{哈希键: 中文}`**，不含英文原文；Anthropic 的英文字符串不随仓库分发。
5. **归档边界**：从 `installer/` 出发递归 import 得到的是活代码，其余归档。
6. **验收层 C 必须在副本登录后进主界面看**。欢迎页由服务端本地化，不是层 C 的产物，不能作为证据。
7. **品牌名、产品名与模型名一律保留英文原文**，不译（`Anthropic`、`Haiku`、`Sonnet`、`Opus`、
   `Windows`、`Chrome`、`Python`…）。守卫测试见 `installer/translations.test.mjs`。

## 怎么验证

```bash
node --test
```

```bash
node installer/install-cli.mjs verify
```

第一条跑全量测试（**不要带目录参数**，见下），约 3 秒，预期 169 项通过、2 项跳过；第二条校验真实安装：
应输出覆盖率 99.52% 与「校验通过」。

深度验证会真开一个 headless 浏览器，跑归档里的 CDP 端到端用例（补齐那 2 项，共 171 项）：

```bash
CDP_E2E=1 node --test --test-force-exit
```

## 已知坑

- **`node --test` 不能带目录参数**：本机 Node v24.18.0 + Git Bash 下 `node --test installer` 会报
  `test at installer:1:1 ✖ installer`（目录被当成文件路径）。裸 `node --test` 才能递归发现全部 171 项。
- **默认跳过 2 项是故意的**：归档里两个 CDP 端到端用例会真开 headless 浏览器，跑起来既依赖本机浏览器，
  其进程句柄又会让测试进程退不出（表现为「测试全过但不返回」）。要用就加 `--test-force-exit`（需 Node 22+），
  见上面的深度验证命令。
- **两份词典必须一起补**：前端把 `i18n/<语种>.json` 与 `i18n/dynamic/<语种>.json` 放在**同一个
  `Promise.all`** 里取，任何一份 404 就 `throw`，整盘词典不加载（回退成空消息、直接显示原始键），
  不会退回英文。官方 11 个语种两份都在，就是这条约束的证据。
- **官方安装目录写不进**：`C:\Program Files\WindowsApps\...` 的 ACL 只给 `TrustedInstaller` 与 `SYSTEM`，
  `Administrators` 也只有 `RX`，提权同样写不进。这是走可写副本的原因。
- **`--user-data-dir` 不可省**：只重定向 `LOCALAPPDATA` 会与官方版抢单实例锁而启动失败。
- **前端构建结构变了就会拒绝安装**：语言白名单锚点必须恰好 2 处，否则退出码 2。官方升级后若安装器报此错，
  说明 `shared-*.js` 结构已变，需要重新定位锚点（见 [`Claude桌面汉化技术设计与首版闭环.md`](Claude桌面汉化技术设计与首版闭环.md)）。
- **注入的 `data-i18n-catalogs` 是惰性标签**：SPA 解析它的正则（在 `shared-*.js` 里）只接受
  「语种:八位.八位」两段，我们注入的三段值匹配不上，`fv()` 返回空数组，该 meta 不参与语言选择。
  **真正生效的是同一段注入里的 `localStorage["spa:locale"]` 与 `shared-*.js` 那两个语种白名单数组。**
  该 meta 目前只是无害的多余字节，换译文不必跟着改版本号。
- **后端不读系统代理**（Node 除外），`maven.google.com` 直连不通属正常，与本项目无关。

## 从零复现

1. 装官方 Claude Desktop（Windows 版）。
2. 装 Node.js LTS（18 以上）。
3. 克隆本仓库，双击 `installer/安装.cmd`。
4. 安装器自动定位官方包 → 复制副本到 `%LOCALAPPDATA%\Claude-zh\package\`（约 700 MB，首次约 30 秒）
   → 打四处层 C 补丁 → 写 locale → 建快捷方式。
5. 首屏登录一次，进主界面验收中文。
