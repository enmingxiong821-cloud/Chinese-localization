## 结论

7 个带真 MIT LICENSE 的现成中文包合计覆盖层 C 键空间的 **93.30%**（31,920 / 34,213），
其中 `javaht/claude-desktop-zh-cn` 一家就占 31,753 条（92.8%）。

## 收官结果（2026-10-14）

**口径**：只取 7 个仓库根目录带真 MIT LICENSE 的来源（javaht、javaht-hardcoded、lijunyu726、
Jyy1529、good9527、Mars-Wang-1988、zhaoxuya520）。另 16 个无许可来源实测只多覆盖 **98** 条，
为这点增量背许可风险不值，**弃用**。

**缺口自译**：2,291 条切 6 批（各约 382 条 / 22k 字符）并行翻译。

**合并与校验**：

```
总键          34213
最终覆盖      33897  = 99.08%
  现成包      31920 条
  自译        1954  条
  改写        23    条（对第三方译文的定点修正）
仍缺          316   条 —— 全部与英文原文一字不差（占位符示例值）
```

**那 316 条不是缺口**：它们是 URL、ARN、UUID、OAuth scope、字体名（`Atkinson Hyperlegible Next`）、
公司名等**本就不该翻译**的示例值。装机时底座是 `en-US.json`，这些键回落即得原文，内容完全一致。
**故实际语义覆盖为 100%。** 逐源条数与许可见 `installer/translations/SOURCES.md`。

**结构校验**：逐条比对 en/zh 的花括号占位符签名、HTML 标签、printf 变量、首尾空白、ICU 类型、
参数顺序：33,897 / 33,897 结构合规，0 错误。

**校验的一条硬性规则 —— `=N` 分支必须保留**：

```
en: {count, plural, =2 {Delete # sessions} other {Delete all # sessions}}
误: {count, plural, other {删除全部 # 个会话}}          ← 选 2 个会话时显示"删除全部"，危险的语义错误
正: {count, plural, =2 {删除 # 个会话} other {删除全部 # 个会话}}
```

本项目约定中文无单复数、ICU `plural` 只留 `other`，但 **`=N` 是精确匹配分支，
与 `one`（纯单复数形态）性质不同，不可一并丢弃**。同类 7 条（`=0`/`=1`/`=2`）已定点修正。

**装机验收**：装入可写副本，重启后首屏**零英文回落**——新建／自定义／更多／最近、
"你启动的会话将显示在这里"、"你来了！"、"今天我能帮你做什么？"、默认模型、项目或文件夹、
给你的建议。截图见 `doc/验收-沙箱中文界面.png`。

## 复现方法

1. `git clone --depth 1` 目标仓库到独立空目录（**不要放进项目目录，不要执行其中任何脚本**）；
2. 以官方 `ion-dist/i18n/en-US.json` 的 34,213 个键为基准；
