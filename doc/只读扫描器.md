# 只读扫描器 M0

当前为无第三方依赖的 Node ESM 技术验证模块，不是完整桌面程序。建议 Node 22 或以上。

执行测试：`node --test project/backend/scanner.test.mjs`

查看用法：`node project/backend/scan-cli.mjs --help`

扫描：`node project/backend/scan-cli.mjs cursor "绝对安装目录"`，或将 cursor 改为 claude。目录为安装根目录，其下应有 resources 文件夹；不自动搜索整个磁盘。路径只作为输入，不写入报告。

只读读取白名单中的 package.json / NLS / 英文语言资源，生成字节数与 SHA-256，并检查 Cursor NLS 结构与键数量。报告不包含资源正文，兼容性始终为 not-verified。

退出码：0 白名单资源读取完成且 Cursor NLS 数量对应；1 缺失、不合法、不可读资源或键数量不对应；2 参数或根目录错误。0 不代表汉化功能验证通过。

限制：每资源最大16MiB；拒绝资源路径中的链接；检查读取期间大小与mtime变化。尚不提供系统I/O硬超时隔离，不是面对恶意并发文件替换的安全沙箱；后续集成需工作进程超时与取消。Claude asar 内部及不同版本目录布局暂不解析，找不到白名单文件必须报告缺失，不能推断不存在i18n能力。

测试创建隔离的合成临时目录，不触碰目标应用。真实应用扫描、语言包生成、桌面接入、OCR与插件均为下一阶段事项。
