# 备份：本地归档

**本目录不进 git**（`.gitignore` 里 `备份/*`，只放行本文件）。里面是从工作区外收进来的、或者不适合入库的资料，
放在这里是为了后续继续开发时能在同一个文件夹里回溯。

| 内容 | 大小 | 说明 |
| --- | --- | --- |
| `会话记录/*.jsonl` | 约 36 MB | 本项目主会话的完整记录 |
| `会话记录/<会话 id>/` | 约 24 MB | 同一会话派生的子代理记录（96 个文件） |
| `安装器-v1.1.zip` | 约 1.1 MB | `installer/` 的离线快照，12 个文件，解压后双击 `安装.cmd` 即可 |

会话记录取自 `%USERPROFILE%\.claude\projects\C--Users-Caspian6610-Desktop-xin\`，原位置仍在，这里是一份副本。

## 边界

- 会话记录含推理与试错过程，按项目约定**不入库**（入库文档只写结论、用法与残留）。
- `安装器-v1.1.zip` 里只有本项目自己的代码与 `{哈希键: 中文}` 译文表，**不含** Anthropic 的英文原文，
  可以安全分发；但因为它与 `installer/` 内容重复，也没有入库。
- 归档不代表内容正确：以 `installer/` 与 [`../README.md`](../README.md) 的当前状态为准。

## 其他只在本机存在的资料

候选语言资源、人工审核产物、调研原文快照等（约 34 MB）**没有复制到这里**——它们本来就在工作区里，
只是被 `.gitignore` 排除。清单见 [`../doc/进度与交接.md`](../doc/进度与交接.md) 的「不进 git 的本地资料」。

## 怎么重建

- 会话记录：Claude Code 自动写在 `%USERPROFILE%\.claude\projects\<项目路径slug>\`，直接复制过来即可。
- 离线安装包：把 `installer/` 整个目录压成 zip，`安装.cmd` 可直接双击。改动过安装器后记得重打。
